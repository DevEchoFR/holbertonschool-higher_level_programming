# JavaScript DOM Manipulation

This project contains small JavaScript exercises focused on selecting DOM elements,
handling click events, updating classes/text, and fetching data from external APIs.

## Learning Objectives

- Select HTML elements with `querySelector`
- Add event listeners with `addEventListener`
- Update styles, classes, and text content
- Create and append DOM nodes dynamically
- Use the Fetch API and handle promises
- Ensure scripts work when loaded from either the `<body>` or `<head>`

## Files

- `0-script.js`: Updates the header text color to red.
- `1-script.js`: Turns the header text red when `#red_header` is clicked.
- `2-script.js`: Adds class `red` to the header when `#red_header` is clicked.
- `3-script.js`: Toggles header class between `red` and `green` when `#toggle_header` is clicked.
- `4-script.js`: Appends `<li>Item</li>` to `.my_list` when `#add_item` is clicked.
- `5-script.js`: Changes header text to `New Header!!!` when `#update_header` is clicked.
- `6-script.js`: Fetches and displays the Star Wars character name in `#character`.
- `7-script.js`: Fetches and lists all Star Wars movie titles inside `#list_movies`.
- `8-script.js`: Fetches and displays French "hello" text in `#hello`.
