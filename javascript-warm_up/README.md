# JavaScript - Warm Up

This project contains introductory JavaScript exercises focused on variables,
arguments, loops, functions, objects, and basic algorithms using Node.js.

## Learning Objectives

- Run JavaScript files with Node.js
- Use variables, constants, and string interpolation
- Read command-line arguments from `process.argv`
- Write loops and conditionals
- Create and call functions
- Work with objects and simple recursion

## Files

- `0-javascript_is_amazing.js`: Prints `JavaScript is amazing`.
- `1-multi_languages.js`: Prints three lines about programming languages.
- `2-arguments.js`: Prints a message based on the number of arguments.
- `3-value_argument.js`: Prints the first argument passed to the script.
- `4-concat.js`: Prints two arguments in sentence format.
- `5-to_integer.js`: Converts the first argument to an integer if possible.
- `6-multi_languages_loop.js`: Prints language lines using an array and loop.
- `7-multi_c.js`: Prints `C is fun` as many times as requested.
- `8-square.js`: Prints a square made of `X` characters.
- `9-add.js`: Adds two integers and prints the result.
- `10-factorial.js`: Computes factorial recursively.
- `11-second_biggest.js`: Finds and prints the second biggest integer argument.
- `12-object.js`: Updates an object value.
- `13-add.js`: Exports a function that returns the sum of two integers.

## How To Run

From this directory, execute any script with Node.js:

```bash
node 0-javascript_is_amazing.js
node 3-value_argument.js School
node 9-add.js 3 5
node 10-factorial.js 5
```

## Notes

- Use executable permissions and shebang when required by your checker.
- Most tasks in this directory are designed to run in Node.js, not in a browser.
